# 🚀 Developer Coding Journal

A full-stack web application built with Python and Flask to log and track daily programming sessions. This project is a foundational piece of my long-term technical growth.

## 🛠️ Features
* **Persistent Storage:** Integrated with an **SQLite database** to store coding sessions permanently.
* **Modern Interface:** Minimalist dark-mode dashboard tailored for software developers.
* **Automated Data Tracking:** Captures hours and timestamps seamlessly via a Python backend.

## 💻 Tech Stack
* **Backend:** Python 3, Flask, SQLite3
* **Frontend:** HTML5, CSS3

## 📦 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd my-coding-journal
   ```
3. Install dependencies:
   ```bash
   pip install flask
   ```
4. Run the application:
   ```bash
   python app.py
   ```
5. Open your browser and navigate to `http://127.0.0.1:8080`.
